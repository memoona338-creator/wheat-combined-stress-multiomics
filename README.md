# Wheat Combined-Stress Multi-Omics Re-Analysis

Analysis scripts accompanying the preprint:

**Multi-Omics Re-Analysis of Transcriptomic and Metabolomic Responses to
Single and Combined Abiotic Stresses in Bread Wheat (Triticum aestivum
L.): Cross-Layer Correlates for Climate-Resilient Breeding**

Memoona Asmatullah

A reproducibility-oriented re-analysis of the public multi-omics dataset
GSE183007 (BioProject PRJNA758708), generated by Da Ros et al. (2023),
The Plant Journal 116(4):1118-1135, doi:10.1111/tpj.16332.

## What this repository contains

Python scripts that reproduce every number, table, and figure reported in
the manuscript, starting from the deposited processed supplementary files.
No raw sequencing reads were re-aligned or re-quantified; all analyses
start from the transcript-abundance and metabolite tables deposited by the
original authors.

## Data used (download separately, not included in this repository)

| File | Source | Description |
|---|---|---|
| Data_S1_phenotypic_metabolic.xlsx | Supplementary Data S1, Da Ros et al. (2023) | Phenotypic, physiological, hormonal and metabolite measurements |
| Data_S2_TPM.xlsx | Supplementary Data S2, Da Ros et al. (2023) / GSE183007 | Transcript-level TPM expression values |
| Data_S3_read_counts.xlsx | Supplementary Data S3, Da Ros et al. (2023) | Transcript-level read counts (consistency checks only) |

Download from GEO (GSE183007) or the journal's Supporting Information
(doi:10.1111/tpj.16332) and place in the repository root before running scripts.
